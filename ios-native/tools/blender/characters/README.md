# Бойцы отряда (WP4 «Отряд») — модели, скелет, клипы

Четыре бойца (`штурмовик`, `огнемётчик`, `криотехник`, `пулемётчик`) строятся процедурно в headless Blender и
отгружаются в `App/Resources/Characters/`:

| Файл | Что |
| --- | --- |
| `marine_<класс>.ihv` | IHV1 v2 со скиннингом (флаги 4 + 8): один меш 8–10 тыс. треугольников (броня, шлем, наплечники, ранец, оружие), общий скелет из 32 костей, 28 клипов с дорожками (half4 поворот + half4 смещение на кость на кадр, 30 кадр/с), сокеты (дуло, фонарь, гильзы, рукояти с рамками кистей) |
| `marine_normal.iht` | массив из 4 слоёв (слой = класс), 1024², ASTC 6×6, касательные нормали, запечённые с high-poly |
| `marine_orm.iht` | массив из 4 слоёв, 512², ASTC 6×6: AO, шероховатость (сношенные фаски глаже), металл (сталь на сношенных фасках окрашенной брони), маска покраски (1 — цвет класса, 0,5 — светлая маркировка) |

```sh
tools/blender/build.sh                               # всё, включая бойцов (characters/build.sh), и гейты
BAKE_CHARACTERS=1 tools/blender/build.sh             # перезапечь карты бойцов (Cycles, ≈ 2 мин на класс) → characters/bake_src
venv/bin/python characters/readback_marines.py App/Resources/Characters OUT [sheet] [strips] [game]
                                                     # лист моделей и полосы анимаций ИЗ ОТГРУЖЕННЫХ ФАЙЛОВ (Cycles)
```

## Файлы

- `skeleton.py` — 32 кости (позы привязки — чистые смещения, A-поза рук 50°), кватернионы, FK, аналитический IK
  на 2 кости. Оружие держится **слева** (+x): ядро выпускает пули из точки «0,95 вперёд, 0,22 влево» (IceHiveCore
  `muzzlePosition`), дула всех четырёх стволов стоят там же (высота 1,10–1,22 м). Кость `ctrl` без вершин несёт
  кривые клипов: вес IK рук (оружейной и опорной), «стопа стоит» для обеих ног, свечение визора.
- `motion.py` — клипы из «описаний поз» (таз и грудь в пространстве модели, голова, оружие, цели IK кистей и стоп):
  стопы стоят на палубе и кисти лежат на рукоятях по построению. Ходьба и бег — параметрическая походка в 8
  направлениях (0 фазы — касание левой стопы, 0,5 — правой; таз проседает при касании, бег — с фазой полёта,
  пятка поднимается к отрыву, бёдра доворачиваются к движению, грудь держит прицел), стиль походки свой у класса.
  Рывок (присед → толчок → посадка → выпрямление, 4 направления), аддитивные «выстрел» (винтовка: отдача через
  корпус, плечи и ствол на каждый выстрел; ротор — дрожь; огнемёт — давление и раскачка; криолуч — гул) и
  «попадание» (спереди / сзади), «ранен» (колени → на колени → ничком), «ползёт» (петля 2 с), «подъём» (на
  четвереньки → на колено → в стойку; приложение проматывает его по прогрессу реанимации), «гибель» (судорога,
  оружие выскальзывает, визор гаснет). Гейты: скольжение стоящей стопы за шаг (0 по построению), ошибка IK (0).
- `subd.py` — моделирование: клетки Catmull–Clark (модификатор Subdivision с заломами кромок; LOW = 1 уровень, HIGH
  = 3 уровня + швы панелей), изогнутые секторные оболочки брони конечностей с завёрнутой внутрь кромкой
  (односторонние: изнутри их не видно), пластины / визоры / полосы, «прилепленные» к готовой поверхности лучами.
  Нормали вершин — numpy (у bmesh они между запусками не побитово одинаковы).
- `marines.py` — каталог деталей: общий корпус + у каждого класса свой силуэт (шлем, наплечники, ранец, оружие),
  материалы, сокеты.
- `shapes.py` — общие примитивы (вращение, призма, болты, прорези).
- `build_marines.py` — сборка класса: объекты по областям, один UV-атлас, запекание (`--bake`) или чтение
  закоммиченного запекания (отпечаток геометрии и UV в `bake_src/bake.json`), экспорт вершин (MikkTSpace,
  v Metal сверху вниз), клипы, сокеты → IHV; массивы текстур → IHT; отчёт.
- `readback_marines.py` — контрольные рендеры отгруженных файлов (позы — CPU-эталон скиннинга `ihv.skin_row`).
